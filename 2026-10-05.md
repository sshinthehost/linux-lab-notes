Day 4 - Package Update and Git Setup

Commands:
sudo apt update
apt list --upgradable
sudo apt upgrade
sudo apt install git
git init
git add .
git commit -m "Initial Linux lab notes"
git push -u origin main

Learned:

sudo runs commands with administrator privileges.

APT manages packages on Ubuntu.

q exits the pager.

Git tracks changes locally.

GitHub stores the repository remotely.

git push uploads commits to GitHub.
